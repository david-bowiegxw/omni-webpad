# Contributing / 参与贡献

Issues and pull requests in English or Chinese are welcome.

Run the packet test, JavaScript syntax check, browser tests, and firmware build described in the README. Keep tests for portrait coordinate transforms, simultaneous sticks, release/cancel behavior, and button bounds when changing the UI. Do not claim console compatibility based on browser tests alone.

For hardware reports, include board, firmware, PS3 model, browser/phone, orientation and reproduction steps. Please omit console flash dumps, device/account identifiers and private network credentials.

欢迎用中文提交问题。修改触摸布局时请验证横竖屏、多指、取消触摸与断线回中，并说明是否经过 PS3 实机测试。
